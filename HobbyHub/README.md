# Hobby Hub Website
Created by Gabriel

This folder contains my complete Hobby Hub website project, including all HTML, CSS, JavaScript, images, models, and supporting files.  
Two local server options are provided so the website can be viewed easily on any computer.

---

## How to Open the Website (PowerShell)

This is the simplest and recommended method.

1. Extract the ZIP file.
2. Locate the file named `server.ps1`.
3. Right-click `server.ps1`.
4. Select **Run with PowerShell**.
5. After the server starts, open your browser and go to:

   http://localhost:8765/

The full website will load locally.

---

## How to Open the Website (Python)

This method is provided as an alternative for systems where PowerShell cannot be used.

1. Ensure Python is installed.
2. Extract the ZIP file.
3. Locate the file named `server.py`.
4. Double-click `server.py` to start the server.
   - A small window will appear indicating the server is running.
   - Your browser will open automatically.
5. If the browser does not open automatically, manually visit:

   http://localhost:8765/

- Closing the PowerShell window or the Python GUI window will stop the server.

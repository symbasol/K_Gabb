What is HTML?

HTML stands for Hypertext Markup Language. It provides the raw structure and content of a web page. It tells the browser what elements exist on the page, such as headings, paragraphs, buttons, and images.

What is CSS?

CSS stands for Cascading Stylesheet. It controls the presentation, layout, and visual design of the HTML content. Without CSS, every website would just look like a plain text document with black text and blue links.

What is JavaScript (JS)?

JavaScript is a full programming language that adds interactivity and dynamic behavior. It allows the web page to respond to user actions without reloading the whole page.
